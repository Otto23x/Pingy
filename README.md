# Pingy

Tracker da ping pong (PWA single-file, offline-first) con arbitro vocale, ELO, tornei, statistiche avanzate, player card e sincronizzazione Google Drive.

- `index.html` contiene tutta l'app: nessun build step, nessuna dipendenza esterna oltre ai font.
- Pubblicala su un hosting https (es. GitHub Pages) per abilitare microfono, fotocamera e OAuth.
